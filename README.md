**Annotate any photo. No Photoshop. No learning curve.**

Mark up floor plans, site photos, inspection images, appraisal reports — in seconds. 17 professional tools, real-world measurement calibration, JPG export. Built for surveyors, real-estate appraisers, inspectors, and field professionals.

## Features

- 🛠 **17 professional annotation tools** — arrows, polygons, measurements, text, callouts
- 📏 **Real-world distance calibration** — 1 pixel = X meters/feet
- 💾 **Save & reload projects** (.pcc format)
- 🖼 **Input:** JPG, PNG, WebP, HEIC, TIFF, PDF
- 📤 **Output:** high-quality JPG export
- ✂️ **Crop & rotate** tools
- 🎨 **Full color & font control**
- 🔒 **100% offline** — no cloud
- ✅ **Notarized** by Apple for macOS, code-signed for Windows
- 💯 **100% free** — no subscriptions, no ads, no telemetry
